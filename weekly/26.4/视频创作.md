# 视频创作 SOP

> 适用：口播类科技观点视频，时长 1-5 min，每条内容独立成段

---

## 单条内容结构

```
【观点】  一句话，有立场，最好反直觉或有判断  
【论据】  链接 / 数据 / 项目 / 截图，必须可溯源、可点击  
【评判】  10-50 字，通俗简洁专业，说人话，要犀利  
```

**Markdown 模板：**

```markdown
## 观点标题（一句话）

> [来源名称](链接) — 一句话说明这条证据讲了什么

个人评判：10-50 字，直接说结论，有立场。
```

---

## 制作步骤

**Step 1 — 定观点**  
先写结论句，不超过 20 字。不能只是描述事实，要有判断（"X 正在发生" 不算，"X 意味着 Y 要死了" 才算）。

**Step 2 — 找论据**  
每条观点配 1-2 个出处，优先选：
- 原始链接（arXiv / GitHub / 新闻原文）
- 具体数字（成功率 3.8%、代码量 100 万行、等待 15 分钟）
- 可演示的项目（能点开 demo 的加分）

**Step 3 — 写评判**  
用自己的话，不超过 50 字。问自己：这件事对我/对普通开发者意味着什么？

**Step 4 — 视频演示顺序**  
```
口播观点（5-10 秒）
  → 切屏展示链接/截图（10-20 秒）
  → 口播评判（5-10 秒）
  → 下一条
```

**Step 5 — 检查**  
- [ ] 每条观点是否有可点击的出处？  
- [ ] 评判是否有自己的立场（不只是复述）？  
- [ ] 全程是否有超过 30 秒没有视觉变化？
