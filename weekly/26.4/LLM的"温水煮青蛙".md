

**LLM 行业正在通过系统性地改造互联网基础设施，制造一种"不得不使用 LLM"的环境**，这是一种精心策划的 `vendor lock-in`（供应商锁定）策略，进行基础设施的异化与计算权力的争夺

---

## 一、基础设施的刻意异化

### 1.1 Agent.txt / Agent.md 的出现

一种新型文件格式的兴起：
- 传统标准：`robots.txt`（用于指示`爬虫`行为）
- 新型替代：`agent.txt`、`agent.md`、`llm.txt` 等

**质疑**：
> "如果 AI 真的这么强大，为什么不能直接解析 robots.txt 并理解它？为什么必须创建一个只能用自然语言解析的文件？"

### 1.2 确定性程序 vs 随机性程序

这种做法的本质：

| 类型 | 特性 | 可用性 |
|------|------|--------|
| 确定性程序（Deterministic Programs） | `输入相同 → 输出相同，可被传统程序解析` | 被刻意排除 |
| 随机性程序（Stochastic Programs，如 LLMs） | 输出具有`随机性，只能被 AI 解析` | 被强制推广 |


> 正在创造一种环境，在这种环境中，除了使用 LLMs 之外，你无法探索信息、无法浏览网站、无法探索项目。他们故意创造了一种你`无法使用确定性程序的基础设施`

**这本质上就是一种 vendor lock-in。**

## 二、文档的"灌水"策略

另一个现象：
- 现在许多项目的文档变成了一堵堵"绝对令人难以忍受的文字墙"
- 没有任何人类愿意去读这些东西

**原因**：

> 为什么这样做？
> 正在创造一种环境，在这种环境中，不得不使用一些的 shit product（垃圾产品）。"
>
> `用大量的噪音淹没环境，迫使不得不使用降噪产品`（LLM 搜索）

这形成了一个恶性循环：
1. 文档质量下降 → 人类难以阅读
2. 人类转向 LLM 搜索
3. LLM 生成内容进一步污染搜索结果
4. 搜索结果变得更糟糕 → 更加依赖 LLM

## 三、信息的"GC 情况"：反复压缩产生的噪声

### 3.1 信息损耗的过程

 LLM 对信息的"污染"：

```
原始信息 → 加入 prompt → LLM 输出（信息 + 噪声）
     ↓
再次被提取/压缩 → 更多噪声
     ↓
再次被 LLM 处理 → 更多噪声
     ↓
重复循环...
```

**过程**：

1. 将想表达的信息放入 prompt
2. LLM 输出一个巨大的文本块，包含你的信息，但被噪声填充
3. 有人尝试把这个输出压缩回有用信息
4. 这个压缩后的信息再被用于其他目的


> 就像一个 GC（垃圾回收/内存压缩）情况——图像不断被放大和压缩，每次都会产生更多的`伪影`（artifacts）、更多的噪声，而你`想分享的原始信息也在这个过程中逐渐丢失`。"

### 3.2 Loss Function 的问题

进一步引申到这个行业的问题：

> "Reinforcement learning 是新的 propaganda school（宣传学校）。"
>
> "我们只想让 loss function 下降，但从来没有问过：loss function 是什么？"
>
> "在试图让 loss function 下降之前，先看看它的定义——我们到底在优化什么？"

## 四、计算权力的争夺

### 4.1 个人计算机的"`去个人化`"

回顾计算的历史：

```
大型机时代（只有大公司能负担）
        ↓
PC 时代（个人化、小型化）
        ↓
现在：正在试图逆转这个个人化进程
```

**观点**：
> "个人计算机给了你自由，而讨厌这一点。`想让计算变得更贵`，让 RAM 价格上涨，让你无法在本地运行模型。"

RAM 价格上涨不是偶然

> "RAM 价格上涨的所有手段都不是偶然的——这不是意外。"

目标

> "最终目标是控制所有的计算能力。想要控制互联网。不想要个人计算机，想要的是`租给你计算能力`。"

## 五、地缘政治视角：LLM 控制的权力博弈

### 5.1 互联网曾是"伟大的均衡器"

> "有人说互联网是强者和劳动者之间的伟大均衡器。"
>
> "但随着 LLM 的普及，加上它们收集的数据，以及人们把它们当作权威来源使用，这种力量可以被反转回强者手中。"

### 5.2 西方公司 vs 中国（CCP）

cn可能利用的一个攻击向量：

```
西方公司：用各种手段让用户`依赖他们的服务`
        ↓
cn/CCP 的可能策略：
"西方的科技公司都在搞这些猫腻，用我们的模型吧——我们的模型容易在消费级硬件上运行，能让你从那些邪恶的科技公司中解放出来"
        ↓
但代价是：这些模型也被 fine-tuned 来推动特定议程
```

> "这是一种有趣的政治斗争方式——即使你在本地运行模型，如果模型被 `poisoning`（投毒），它也可以推送特定的议程。"

## 六、Neuralink：不可逾越的红线

### 6.1 明确立场

> "绝对不会往脑子里植入任何能连云端的东西的。那是 red line of red lines（红线中的红线）。"

### 6.2 温水煮青蛙的策略

警告潜在的温水煮青蛙策略：

**当前情况（LLM）**：
1. 创造一个难以不使用 LLM 的环境
2. 搜索引擎被 LLM 内容淹没
3. 最终你"不得不"使用 LLM

**应用到 Neuralink**：
1. 同样采用温水煮青蛙的策略
2. 逐渐创造"没有脑机接口`就无法生活"的环境`
3. "你不能买东西，不能上网，不能做任何事"
4. 最终即使那是红线，你也没有选择

**具体威胁场景**：

- **Brain verification for web access**：未来可能需要脑部验证才能上网
- **Job requirement**：工作可能要求安装 Neuralink
- **社会排斥**：没有植入物的人被边缘化

> "可以说'我不会往脑子里放任何东西'，但他们会开始慢慢煮青蛙——创造一种环境，让不植入芯片就无法做任何事。就像智能手机一样，`创造了一个没有选择的环境`。"

## 七、LLM 使用的真实成本

### 7.1 LLM 并不"方便"

反驳"LLM 方便"的观点：

> "实际上，如果正在做困难的事情，LLM 使用起来并不特别方便。"
>
> "必须把整个思维模型翻译成英语，放进那个 cancerous（癌变的）输入框里，这需要大量努力——它实际上会打断你的思考过程。"

### 7.2 输入瓶颈

> "我们应该有一种更快的方法，把`思维模型`从大脑里拿出来，放进那个 cancerous 机器里。"
>
> "因为真正的瓶颈在于——`prompt` 输入框是人类大脑和人工大脑之间极其狭窄的`瓶颈`。"

### 7.3 自然语言 vs 合成语言

> "使用自然语言比使用合成语言更难。Neural interface 可能是解决这个问题的方案。"

但考虑到 Neuralink 的危险，这个"解决方案"可能比问题本身更糟。

## 八、如何对抗这种"邪恶"

### 8.1 不主动对抗

> "你不能通过积极与邪恶作斗争来对抗邪恶——因为唯一能打败邪恶的方式就是让自己变成邪恶。"
>
> "试图摧毁数据中心什么的，那本身就是邪恶的——那是别人的财产，数据中心有有价值的计算能力，可以用于好的目的。"

### 8.2 正确的方式：暴露和揭示

> "邪恶获取力量的方式是：让人们不知道它正在使用的伎俩。"
>
> "真正的对抗方式是：暴露和展示所有这些伎俩。'看，这就是他们在做的事情。'"
>
> "让人们意识到这一点，然后他们会说：'好的，我看到了你们在做什么。我不会参与其中。'"

### 8.3 避免被激怒

> "暴力本身就是邪恶——你变成了邪恶，那就是邪恶使用的伎俩之一：试图引诱你变成邪恶。"

## 十、注释

| 术语 | 原文 | 解释 |
|------|------|------|
| Vendor lock-in | 供应商锁定 | 使用户无法轻易切换到其他供应商的策略 |
| Deterministic program | 确定性程序 | 相同输入必产生相同输出的程序 |
| Stochastic program | 随机性程序 | 输出具有一定随机性的程序 |
| Loss function | 损失函数 | 机器学习中被优化的目标函数 |
| Reinforcement learning | 强化学习 | 一种机器学习方法 |
| Fine-tuning | 微调 | 在预训练模型基础上进行的定制化训练 |
| Poisoning | 投毒 | 在模型或数据中植入恶意内容 |
| GC (Garbage Collection) | 垃圾回收/内存压缩 | 比喻信息反复压缩产生的损耗 |
| Neural interface | 神经接口 | 连接人脑与计算机的接口技术 |
