## 1. 背景引入：为什么需要生成式AI

### 1.1 传统AI vs 生成式AI

| 时期 | AI类型 | 核心功能 | 代表任务 |
|------|--------|----------|----------|
| 2010-2020 | 传统AI | **认识世界** | 分类、识别、预测、控制、决策 |
| 2020至今 | 生成式AI | **改造世界** | 内容生成、创作 |

传统AI从已知数据中学习规律并应用，局限于已有认知

生成式AI则能够创造全新的内容

### 1.2 生成式AI的里程碑

- **ChatGPT (2022)**：让生成式AI走进大众生活
- **Decision Policy (2023)**：将DDPM应用于机器人动作规划
- **即梦（2024）**：视频生成模型

### 1.3 三种主流架构

三种生成式AI架构：

1. **VAE** (Variational Autoencoder) - 变分自编码器
2. **DPM/DDPM** (Diffusion Probabilistic Model) - 扩散概率模型
3. **Flow Matching** - 流匹配

## 2. 生成式AI的核心问题

### 2.1 内容的数学表示

==所有数据都可以用向量表示==

```
图像 → 像素值(H×W×RGB) → 高维向量
视频 → 图像 + 时间维度 → 高维向量
动作 → 动作维度 → 动作向量空间
```

> **数据集 = 大量向量的集合**

### 2.2 生成内容的数学建模

```
目标：从数据分布 P_data 中采样生成新内容
```

在高维空间（维度记为D）中：
- 真实数据分布 $P_{data}$ 就像"飘在房间里的丝带"，非常稀疏
- 大部分空间都是噪声
- 难以直接建模和采样

### 2.3 核心问题的解决思路

三种方法都是围绕**如何从复杂分布中采样**这一问题展开：

| 方法 | 解决思路 |
|------|----------|
| VAE | 降维 + 引入简单先验分布 |
| DDPM | 逐步加噪/去噪 |
| Flow Matching | 分布之间的最优流动路径 |

## 3. VAE（变分自编码器）

### 3.1 核心思想

VAE解决两个核心问题：
1. **真实分布 $P_{data}$ 难以获得**
2. **复杂分布难以直接采样**

**解决方案**：
- 引入**隐空间**和**隐变量 Z**
- 通过降维在低维空间学习分布（更密集，便于采样）
- 让隐变量服从简单的**标准正态分布**（高斯分布易于采样）

### 3.2 为什么需要VAE而非直接用AE？

AE（自编码器）的encoder将输入映射为隐空间中的**离散点**，无法直接采样生成新内容。

VAE的改进：
- 将每个输入映射为一个**正态分布**
- 让所有分布尽可能接近标准正态分布
- 生成时直接从标准正态分布采样，再经decoder生成

### 3.3 VAE为什么能产生新内容？

```
图片A的分布 + 图片B的分布 → 交界处融合 → 新内容
```

不同图片映射的分布交界处具有**两种图片的共同特征**，decoder通过这个交点生成新内容。

### 3.4 VAE结构

```
输入X → Encoder Q(z|X) → 隐变量Z的分布 → Decoder P(X|z) → 输出
```

- **Encoder**：输出隐变量 Z 的均值 μ 和方差 σ²（正态分布参数）
- **Decoder**：将隐空间输入映射为正态分布，取均值作为输出
- **训练**：前向传播计算输出 → 反向传播计算loss

### 3.5 VAE的损失函数

VAE的loss由两部分组成：

```
L = L_reconstruction + L_KL
```

#### 3.5.1 图片重建误差（Reconstruction Loss）

计算decoder输出与输入的均方误差（MSE）：

```
L_reconstruction = MSE(X_output, X_input)
```

保证输出图片与输入一致。

#### 3.5.2 Q散度（KL散度）

约束隐变量分布接近标准正态分布：

```
L_KL = D_KL(Q(z|X) || N(0,1))
```

最终可简化为（详细推导见VAE原论文）：
- 隐变量分布与标准正态分布的KL散度

#### 3.5.3 两个loss的制衡关系

| 倾向 | 效果 |
|------|------|
| 过于倾向重建误差 | 生成内容过于接近数据集，缺乏创新性 |
| 过于倾向KL散度 | 融合过多，产生不希望的新内容 |

### 3.6 重参数化技巧（Reparameterization Trick）

**问题**：采样过程是离散的，涉及随机量，无法直接反向传播。

**解决方案**：将随机性隐藏在噪声 ε 中

```
Z ~ N(μ, σ²) 可写成：
Z = μ + σ · ε,  其中 ε ~ N(0,1)
```

- Z 对 μ 和 σ 都是可导的
- 所有随机性隐藏在 ε 中
- 保证反向传播的连续性

### 3.7 VAE存在的问题

| 问题 | 描述 | 原因 |
|------|------|------|
| 损失函数相互制约 | 训练不稳定 | 两个loss项互相制衡 |
| 后验坍塌（Posterior Collapse） | 生成内容与输入无关 | Decoder能力过强，不依赖隐变量 |
| 一次性加噪/去噪困难 | 去噪困难 | 加噪容易但还原难（像把画涂黑容易，还原难） |

## 4. DDPM（扩散概率模型）

### 4.1 核心思想

DDPM针对VAE"一次性加噪/去噪"的问题进行改进：

> **从加噪过程中学习如何逐步去噪**

类比：
- 一次性涂黑画容易，但还原难
- 一笔一笔画，再一笔一笔去除，容易得多

### 4.2 数学建模

将加噪和去噪过程建模为**马尔可夫链**：

```
噪声 X_T → 逐步去噪 → X_{T-1} → ... → X_1 → X_0 生成内容
```

**训练过程**：从数据集逐步加噪变纯噪声，学习去噪

**生成过程**：从纯噪声逐步去噪得到新内容

### 4.3 前向过程（加噪/熵增）

#### 4.3.1 逐步加噪

设步数为 T，每步添加高斯噪声，参数 β_t 逐渐递增：

```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t)·x_{t-1}, β_t·I)
```

#### 4.3.2 关键性质

通过数学推导，可以将 T 步加噪**一步完成**：

```
q(x_t | x_0) = N(x_t; √ᾱ_t · x_0, (1-ᾱ_t)·I)
```

其中：
- $\alpha_t = 1 - \beta_t$
- $\bar{\alpha}_t = \prod_{i=1}^{t} \alpha_i$（累积）

当 t → T 时：
- $\sqrt{\bar{\alpha}_t} \to 0$（均值趋于0）
- $(1-\bar{\alpha}_t) \to 1$（方差趋于标准正态分布）

**所有图片最终都会变成标准正态分布，便于采样**

#### 4.3.3 为什么不能直接注入高斯噪声？

如果直接注入均值0、方差I的高斯噪声，每个图片最终服从的是**不同均值 x_0 的分布**，采样仍然困难。

### 4.4 逆向过程（去噪）

#### 4.4.1 目标

学习后验分布 $q(x_{t-1}|x_t)$，实现从 $x_t$ 到 $x_{t-1}$ 的转移。

#### 4.4.2 贝叶斯公式推导

```
q(x_{t-1}|x_t) = q(x_t|x_{t-1}) · q(x_{t-1}) / q(x_t)
```

三项分析：
- $q(x_t|x_{t-1})$：已知的前向转移概率（高斯分布）
- $q(x_{t-1})$：难以直接求得
- $q(x_t)$：对所有 x_0 积分，几乎不可能求

#### 4.4.3 引入 x_0 简化

已知 x_0 时，$q(x_t|x_0)$ 可直接计算：

```
q(x_t|x_0) = N(x_t; √ᾱ_t · x_0, (1-ᾱ_t)·I)
```

三项都是高斯分布，可推导 $q(x_{t-1}|x_t)$ 的均值和方差。

#### 4.4.4 关键结论

推导结果显示，$q(x_{t-1}|x_t)$ 的均值和方差的计算中：
- **σ²**：已知参数
- **μ**：需要预测的是噪声 ε（或等价地预测 x_0）

### 4.5 训练目标

**核心结论：神经网络只需要预测噪声 ε**

```python
# DDPM训练伪代码
for x_0 in dataset:
    t ~ Uniform({1, ..., T})      # 随机采样时间步
    ε ~ N(0, I)                   # 采样噪声
    x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε  # 加噪
    ε_θ = network(x_t, t)        # 预测噪声
    loss = MSE(ε_θ, ε)           # 最小化预测误差
```

### 4.6 生成过程

```
1. 从 X_T ~ N(0, I) 采样
2. for t = T to 1:
       预测噪声 ε_θ
       计算 μ_θ = (x_t - √(1-ᾱ_t)·ε_θ) / √ᾱ_t
       计算 σ²_θ（已知）
       从 N(μ_θ, σ²_θ) 采样得到 x_{t-1}
3. 返回 x_0 的均值作为生成结果
```

- 生成过程类似VAE从标准正态分布采样
- 区别：decoder变成了层层去噪网络
- 训练更稳定，生成效果更稳定

### 4.7 Decision Policy示例（2023）

将DDPM应用于机器人动作规划：
- 从完全噪声逐步生成规划动作
- 具有良好的多模态建模能力
- 视频演示：噪声 → 逐步去噪 → 生成完整动作序列

## 5. Flow Matching（流匹配）

### 5.1 从新角度理解生成问题

回顾初心：学习目标数据分布 $P_{data}$ 并从中采样

DDPM实际上实现了：
```
P_noise (高斯分布) → 逐步转移 → P_data
```

### 5.2 SDE与ODE视角

#### 5.2.1 DDPM的SDE表示

DDPM的加噪去噪过程可以写成**随机微分方程（SDE）**：

```
dx = f(x, t) dt + g(t) dw
```

描述的是：分布如何从 $P_{noise}$ 流动到 $P_{data}$

#### 5.2.2 DDPM的问题

每一步都需要采样噪声并去噪，流动路径**非常波折**

#### 5.2.3 Flow Matching的改进

**目标**：找到**最优流动路径**，提高采样效率

### 5.3 Flow Matching核心思想

用**常微分方程（ODE）**替代SDE：

```
d x_t / dt = u_θ(x_t, t)
```

- $u_θ(x_t, t)$：**向量场**（velocity field），描述数据流动的方向和速度
- 学习目标是拟合这个向量场
- ODE比SDE更高效（无随机项）

### 5.4 关键概念

#### 5.4.1 向量场（Vector Field）

$u_θ(x_t, t)$ 描述了数据流动的本质规律，是训练过程中需要学习的参数。

#### 5.4.2 轨迹（Trajectory）

某个数据点从初始分布流向目标分布形成的路径：

```
时间 T ∈ [0, 1]
轨迹: x_0 → x_1
```

#### 5.4.3 概率路径（Probability Path）

一组轨迹组成的集合 $\{p_t\}$，描述整个分布的流动过程。

### 5.5 高斯-高斯传输路径（Gaussian-Gaussian Path）

最常用的传输路径设计：

```
均值: μ_t = (1 - β_t) · x_0 + β_t · z
方差: σ_t² = β_t² · I
```

其中：
- $x_0$：目标数据点
- $z$：标准正态分布样本
- β_0 = 0, β_1 = 1

当 t=0 时：分布 = 标准正态分布 $N(0, I)$
当 t=1 时：分布 = 目标数据点 z

#### 5.5.1 概率路径的物理含义

```
x_t = (1 - β_t) · x_0 + β_t · z
```

是 z 和 x_0 连线上的一个点（线性插值）

### 5.6 向量场的解析解

概率路径满足ODE，对路径求导可得目标向量场：

```
u_t(x_t | z) = (1 - β_t)' · x_0 + β_t' · z
             = z - x_0（代入β_t = t, 1-β_t = 1-t）
```

### 5.7 训练目标

```python
# Flow Matching训练伪代码
for z in dataset:                    # 从数据集采样目标点
    t ~ U(0, 1)                      # 随机时间
    x_t = (1-t)·x_0 + t·z            # 计算中间点
    u_θ = network(x_t, t)            # 预测向量场
    u_target = z - x_0               # 目标向量场
    loss = ||u_θ - u_target||²       # MSE损失
```

**核心结论**：训练目标等价于让网络学习 $z - x_0$

### 5.8 生成过程

```python
# 离散化ODE求解
x_1 = x_0
for h in timesteps:                  # 从0到1迭代
    dx = u_θ(x_t, t) · dt
    x_t = x_t + dx                   # 更新
return x_1
```

本质：解ODE方程，从噪声分布生成目标数据。

### 5.9 Flow Matching的优势

| 对比项 | DDPM | Flow Matching |
|--------|------|---------------|
| 路径 | 随机、波折 | 最优、直滑 |
| 采样效率 | 低（需1000步） | 高（收敛更快） |
| 多样性 | 高（随机性） | 可控（无随机项） |
| 框架灵活性 | 固定 | 可设计不同传输路径 |

### 5.10 实验对比

#### 5.10.1 噪声强度实验

增加噪声强度：
- Flow：更顺滑地达到目标分布
- DDPM：需要更多努力到达目标

#### 5.10.2 拟合椭圆分布（2000步采样）

| 模型 | 效果 |
|------|------|
| DDPM | 仍呈杂乱状态 |
| Flow Matching | 基本收敛到目标椭圆分布 |

### 5.11 为什么说Flow Matching是大势所趋？

1. **更高效的流动路径**：采样效率更高
2. **更灵活的框架**：可以设计不同的传输路径
3. **更广泛的范式**：为后续研究提供基础

## 6. 三种方法的对比与总结

### 6.1 发展脉络

```
VAE → DDPM → Flow Matching
```

| 方法 | 核心思想 | 关键创新 |
|------|----------|----------|
| VAE | 降维 + 隐变量先验 | 引入隐空间、重参数化技巧 |
| DDPM | 逐步加噪/去噪 | 马尔可夫链、预测噪声 |
| Flow Matching | 最优流动路径 | ODE、无需随机采样 |

### 6.2 数学框架对比

| 方面 | VAE | DDPM | Flow Matching |
|------|-----|------|---------------|
| 分布转移 | 一步到位 | 离散马尔可夫链 | 连续ODE |
| 采样 | 从先验直接采样 | 逐步去噪 | 解ODE |
| 随机性 | 隐变量服从分布 | 每步随机 | 无（确定性） |
| 训练目标 | 重建 + KL | 预测噪声 | 预测向量场 |

### 6.3 各方法优缺点

#### VAE

| 优点 | 缺点 |
|------|------|
| 结构简单 | 两个loss相互制约 |
| 训练高效 | 后验坍塌问题 |
| 生成快速 | 生成质量一般 |

#### DDPM

| 优点 | 缺点 |
|------|------|
| 生成质量高 | 采样步数多（慢） |
| 多样性好 | 计算开销大 |
| 理论基础强 | 随机性导致效率低 |

#### Flow Matching

| 优点 | 缺点 |
|------|------|
| 采样效率高 | 理论推导复杂 |
| 框架灵活 | 多样性可能降低 |
| 统一多种方法 | 实际应用还在探索 |

### 6.4 核心公式汇总

#### VAE

```
隐变量: Z = μ + σ · ε,  ε ~ N(0,1)
Loss: L = MSE(X_out, X_in) + D_KL(N(μ,σ²) || N(0,1))
```

#### DDPM

```
加噪: x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε
去噪: 学习预测 ε
生成: x_{t-1} ~ N(μ_θ, σ²_θ)
```

#### Flow Matching

```
概率路径: x_t = (1-t)·x_0 + t·z
向量场: u_t = z - x_0
ODE: dx/dt = u_θ(x_t, t)
```

### 6.5 共同思想

三种方法的共同本质：==**从简单分布（标准正态分布）出发，学习如何到达复杂目标分布**==
