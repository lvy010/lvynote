## libra

**Git 原本用自己发明的"文件夹+特殊格式文件"来存储代码历史，libra 改用了现成的数据库软件 SQLite 来存，就像把账本从手写本换成了 Excel。**

---

## 类比

| 对比维度     | 传统 Git                          | libra                   |
| ------------ | --------------------------------- | ----------------------- |
| **存储方式** | 自定义文件格式（`.git/objects/`） | SQLite 数据库文件       |
| **类比**     | 手工记账本 📓                      | Excel 表格 📊            |
| **优势**     | 为版本控制专门优化                | 可以用 SQL 查询，更灵活 |

---

## 为什么要这样改？

**传统 Git 的问题：**
```bash
.git/objects/a1/b2c3d4e5f6...  # 文件名是哈希值，人类看不懂
.git/refs/heads/main           # 分散在多个文件夹
```

**libra 的改进：**
```sql
SELECT * FROM commits WHERE author = 'lvy010';  -- 可以直接用 SQL 查询
```
