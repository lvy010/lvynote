# 数据迁移文件说明

`orion-server/migration/create_targets_table.rs` 是**数据库迁移脚本**，它的作用是：

### 理解

想象数据库是一个 Excel 表格：

**之前的表格结构：**
```
builds 表：
| id | task_id | target (文本) | status |
|----|---------|---------------|--------|
| 1  | task1   | "//app:server"| 成功   |
```

**现在需要改成：**
```
targets 表（新建）：
| id | target_path    | state   | start_at | end_at |
|----|----------------|---------|----------|--------|
| t1 | "//app:server" | Success | 10:00    | 10:05  |

builds 表（修改）：
| id | task_id | target_id (关联) | status |
|----|---------|------------------|--------|
| 1  | task1   | t1               | 成功   |
```

---

## 🎯 这个文件的三个作用

### 1️⃣ **创建新表** (targets)
```rust
// 创建一个新的"目标表"，用来存储每个构建目标的信息
CREATE TABLE targets (
    id UUID PRIMARY KEY,           // 唯一标识
    target_path VARCHAR NOT NULL,  // 目标路径，如 "//app:server"
    state VARCHAR NOT NULL,        // 状态：Building/Completed/Failed
    start_at TIMESTAMP,            // 开始时间
    end_at TIMESTAMP,              // 结束时间
    error_summary TEXT             // 错误信息
)
```

### 2️⃣ **修改旧表** (builds)
```rust
// 在 builds 表中添加一个新列 target_id
ALTER TABLE builds ADD COLUMN target_id UUID;

// 删除旧的 target 文本列（因为现在用 target_id 关联了）
ALTER TABLE builds DROP COLUMN target;
```

### 3️⃣ **数据迁移**（把旧数据搬到新结构）
```rust
// 把旧的 builds 表中的 target 文本转换成 targets 表的记录
// 例如：builds 中有 "//app:server"，就在 targets 表创建一条记录
// 然后把 builds.target_id 指向这条新记录
```

---

## 可以删掉吗？

### ⚠️ **不能删！** 原因如下：

| 场景         | 如果删除会怎样                                               |
| ------------ | ------------------------------------------------------------ |
| **首次部署** | 数据库中没有 `targets` 表，程序启动会报错："找不到 targets 表" |
| **已有数据** | 旧的 `builds` 表中的数据无法转换到新结构，历史数据丢失       |
| **团队协作** | 其他开发者拉取代码后，数据库结构不一致，无法正常工作         |

---

## 它是怎么工作的？

### 运行时机
当启动服务器时，系统会自动检查：

```bash
# 服务器启动时
1. 检查数据库版本：当前是 v1.0
2. 发现有新的迁移文件：m20260113_create_targets_table.rs
3. 自动执行迁移：
   ✅ 创建 targets 表
   ✅ 修改 builds 表
   ✅ 迁移旧数据
4. 更新数据库版本：v1.0 → v1.1
5. 完成！现在可以使用新功能了
```

### 类比理解
就像手机系统升级：
- **迁移文件** = 系统更新包
- **数据库** = 你的手机
- **运行迁移** = 安装更新

如果删除更新包，手机就无法升级到新版本。

## 📚 常见问题

### Q1: 这是测试文件吗？
**A:** 不是！==这是**生产环境必需的文件**，用于升级数据库结构==。

### Q2: 我已经手动创建了 targets 表，可以删吗？
**A:** 不建议删除，因为：
- 其他环境（测试/生产）还需要这个文件
- 团队其他成员需要这个文件来同步数据库结构
- 未来回滚时需要用到

### Q3: 文件里提到的 `gen_random_uuid()` 是什么？
**A:** 这是 PostgreSQL 数据库生成唯一 ID 的函数，类似于：
```sql
-- 为每条记录生成一个唯一的 ID，像这样：
"a1b2c3d4-e5f6-7890-abcd-ef1234567890"
```

如果数据库报错说找不到这个函数，需要先运行：
```sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;
```
